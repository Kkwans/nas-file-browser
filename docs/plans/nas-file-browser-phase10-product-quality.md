# NAS File Browser Phase 10 产品质量与体验计划

## 目标与边界

Phase 10 继续在现有 P0–P2 与 Phase 9 发布成果上迭代，优先解决真实使用中的媒体打开卡顿、失败后假死和重复读取，再统一文件资源图标、侧栏图标、响应式与无障碍，最后评估高价值扩展能力。

功能正确性、UI 质量和用户体验优先，不设固定性能提升百分比，但关键操作不得明显回退。保留现有品牌、真实缩略图、管理员 NAS 原生根目录、用户数据以及移动端“单击按压反馈、双击打开、长按选择、滚动不误触”契约。

### 媒体链路

- Compose 未配置持久缩略图缓存；Backend 实际使用 `diskcache.NoOp`，每次预览均重新读盘、解码、缩放和编码。
- 图片预览服务全局并发为 1，但列表缩略图、当前大图和相邻大图预取没有优先级。
- 路由进入预览时，旧文件列表尚未立即取消 `<img>` 和视频封面请求，浏览器连接池被占满。
- `ExtendedImage` 只有成功状态，没有加载失败、超时、重试和直接打开兜底，错误会永久显示“加载中”。
- TIFF/RAW 使用完整 XHR、主线程同步 UTIF 解码和 `toDataURL`，且路由离开时没有可靠中止。
- 图片仅限制单边尺寸，没有总像素限制；极端图片可能造成高内存占用。
- 播放位置 GET/PUT 使用完整资源展开，会重复检测类型和扫描父目录；前端约每 2 秒保存并可能并发重叠。
- 已知不兼容视频仍先绑定原始源，MKV 被错误标记为 `video/mp4`；兼容播放启动时原始读取没有立即释放。
- 恢复进度在元数据就绪时立即远距离 seek，可能在用户尚未播放时触发额外 Range 与解码。
- 文件路由以完整 URL 作为组件 key，资源元数据到达前可能先挂载旧 Preview，再切换一次。

### UI、图标与响应式

- 文件图标的窄屏 CSS 仍假设旧 DOM 层级，实际尺寸与设计值不一致；四种布局缺少统一尺寸 Token。
- 紧凑列表会隐藏风险标识；真实媒体缩略图优先时，中高风险媒体可能完全失去风险语义。
- 侧栏展开态把 20px 图标强制为 28px，折叠图标轨却为 21–22px，切换时视觉跳变明显。
- 同一页面混用 Lucide 线性图标与 Material Filled 字体图标，线宽、基线和视觉重量不统一。
- 文件、压缩包、集合、权限与风险语义存在重复或冲突映射；TS 图标映射与 CSS 伪元素映射也会分叉。
- 侧栏部分图标入口缺少可靠的 `aria-label`、语义按钮和 44px 命中区域。
- 容器响应式逻辑与部分 viewport media query 并存，窄侧栏和窄窗口下可能得出不同布局结果。

## 优先级与实施阶段

## P0：媒体打开速度与可靠性

### Phase 10A：当前媒体优先

**技术方案**

- 路由进入预览后立即挂起旧文件列表的图片和视频封面请求，取消尚未完成的调度任务并清除原生 `<img src>`。
- 当前媒体成功加载前禁止相邻大图预取；成功后仅在浏览器空闲时低优先级预取下一项，路由变化立即取消。
- 图片预览建立明确的 `loading / ready / error` 状态，提供重试、直接打开或下载兜底，不允许无限加载。
- 保持真实缩略图、前后导航和四种布局，不以关闭预览功能换速度。

**验证**

- 组件状态和调度单测、Frontend lint/typecheck/test/build。
- 使用与基线相同的图片、目录、viewport 和网络记录复测直接打开与列表打开。
- 验收重点：目标资源请求应在点击后立即开始；旧缩略图请求应被取消；失败图片不再假死。

### Phase 10B：有界缓存与大图安全

**技术方案**

- 配置持久预览缓存并设容量上限、LRU 清理、原子写入和源文件身份失效；缓存写失败不应导致本次预览失败。
- 当前大图与交互预览优先于列表缩略图；保持 NAS 友好的低并发，不简单提高线程数。
- TIFF/RAW 默认由服务端生成浏览器原生格式预览，前端同步 UTIF 仅作为受控兜底，并支持取消。
- 增加总像素、预计内存和解码超时防护；失败进入短时冷却，避免无限重试。
- 命中不可变文件身份时返回合适的缓存头，减少重复网络和解码。

**验证**

- 冷/热缓存、缓存失效、容量回收、损坏缓存、写失败和取消测试。
- JPEG/PNG/GIF/WebP/TIFF/RAW、超大尺寸和损坏文件的真实浏览器测试。
- 记录冷开、热开和失败恢复时间，不以牺牲画质作为通过条件。

### Phase 10C：视频请求与播放位置

**技术方案**

- 播放位置读写使用轻量文件身份，不展开资源和扫描父目录；Backend 单事务更新。
- 前端保存间隔调整为低频去抖并合并并发请求；暂停、离开和结束时执行最终保存。
- 已知不兼容格式不预先绑定原始视频；MIME 使用真实映射，启动兼容播放前释放原始源。
- 首次用户播放后再恢复远距离进度，避免未播放就触发额外 seek。
- 修复预览组件路由生命周期，确保每次导航只为目标资源初始化一次。
- 视频封面浏览器任务增加硬超时和离屏取消，Canvas 使用异步 Blob；FFmpeg 封面限制内部线程并去除音频、字幕和数据流。

**验证**

- 播放位置读写、请求合并、路由切换、已知兼容/不兼容格式和 HLS 回归测试。
- NAS 本机 Playwright 记录首帧、可交互、Range 请求数量、取消和兼容播放状态；历史 TX5pro 报告仅作为既有证据保留。

## P1：文件区与导航视觉质量

### Phase 10D：统一资源图标

- 以 `--resource-icon-size` 统一四种布局和容器断点，图标外壳、真实缩略图、普通图标和风险图标共享同一尺寸来源。
- 建立单一 `ResourceIcon` 语义映射，复用现有 `AppIcon`、`FileThumbnail` 与风险组件，移除重复 CSS 伪元素映射。
- 紧凑布局和真实缩略图旁保留可读的中高风险语义，不能只靠颜色，也不能恢复错位小圆点。
- 文件夹图标按普通、中风险、高风险、系统、共享、收藏/集合等真实语义区分，但维持同一造型家族和视觉重量。
- 校准图标光学中心、线宽、名称基线和选中/禁用/风险对比度。

### Phase 10E：侧栏与全站响应式

- 侧栏展开态和图标轨使用一致的 20–22px 视觉图形与 44px 命中区域，不再把 SVG 强制放大到 28px。
- 将残留 Material Filled 图标迁移到本地 Lucide 包装层，补齐 Tooltip、`aria-label`、按钮语义和键盘状态。
- 统一容器宽度为文件工作区决策源，梳理与 viewport media query 冲突的规则。
- 对 Files、Search、Recent、Trash、Tasks、History、Analysis、Settings 和 Preview 逐页检查字号、留白、溢出、操作密度、空错状态和 Dark Mode。
- 不引入彩色左边条、胶囊堆叠、装饰性渐变或逐项级联动画；保留现有品牌方向。

## P2：可扩展能力候选

以下功能只在 P0、P1 独立验收后进入实现排序；先复用现有媒体、任务和偏好架构，再确认产品语义，不提前建立重复系统。

- **媒体性能诊断面板**：管理员可查看当前预览队列、缓存命中、失败冷却与转码任务，支持复制脱敏诊断信息。
- **用户主动预热**：仅对用户选中的目录或收藏分组生成缩略图，进入任务中心，支持取消、限速和磁盘上限；禁止后台全盘扫描。
- **媒体信息与快速定位**：复用现有预览，增加可折叠元数据、所在目录定位和最近失败原因，不把内部路径或原始任务结果直接暴露。
- **图片对比与基础管理**：在当前目录选择 2–4 张图片进行并排/擦除对比，操作仍复用现有收藏、标签、移动和删除接口。
- **视频章节与字幕体验**：优先读取内嵌/同名字幕与章节，允许用户显式切换；不自动修改源文件。
- **缓存管理**：管理员查看占用、命中率和按类别清理；清理必须保护正在使用的产物并提供确认与结果报告。
